`TwemojiCountryFlags.woff2` is from
[country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill)
0.1.10. Windows has no flag emoji (it shows 🇬🇷 as "GR"), so index.org's
`@font-face` uses this font for flag characters only; browsers download it
only when a flag is on screen.

The flag art is [Twemoji](https://github.com/twitter/twemoji), © Twitter,
