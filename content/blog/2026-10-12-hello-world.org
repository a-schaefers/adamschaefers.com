#+TITLE: Hello, world
#+DESCRIPTION: How this site is built, served and shipped.

This site is written in Emacs Org mode and built into a TypeScript, lit-html and Tailwind single-page app.

Every view is prerendered at its own address, so crawlers and link previews see real pages without running JavaScript.

It moved from GitHub Pages to Cloudflare Workers Static Assets, with content-hashed assets cached forever and media served from R2.

Three Workers run the site, the contact form, and a Stripe-backed store built to sell anything, starting with software licenses.

CI/CD is GitHub Actions: every change is a pull request on a protected =master=, gated by one required check that builds the site, checks every link, typechecks every TypeScript project and runs the Workers' tests in seconds. The merge is the deploy: the merged commit is built again, shipped to Cloudflare with only the changed files uploaded and switched atomically, then smoke-tested live, with one-command rollback. Actions are pinned to commits and bumped by Dependabot, and the only deploy credential is a token scoped to the three Workers that pull requests can never read.
